# Sample policies and decks

This directory contains small runnable policy/deck fixtures rather than generated output.

- `starmie-froslass/deck.csv` is the default deck used by `configs/starmie_froslass.json`.
- `mega-lucario-ex/` preserves the original standalone Lucario policy and deck.
- `mega-lucario-v62/` preserves the later raw Kaggle-style policy used by smoke tests and its matching config.

Generated `__pycache__` and operating-system metadata should not be retained here.
